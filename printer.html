Printer setup

For the machine people deposit from. Set this up once and it keeps working every time the site is opened on this device, until it's switched off here.

1. Get the bridge

A browser can't talk to a printer, so a small program sits in between. It needs Node and nothing else. Put these in a folder on the computer the printer is attached to.

server.js start.command mac start.bat windows README.md

server.js is the one that matters. Take the launcher for whichever computer the printer is on and double click it: start.command on a Mac, start.bat on Windows. Both open a window that stays open, so if something is wrong you can read why.

Or run it yourself from a terminal in that folder:

node server.js --target console

Receipts come out with nabii's logo and little note dividers. If the printer is an older one that can't do graphics and those arrive as garbled characters, start it with --nologo and it falls back to plain text.

You don't need to name a printer here. Start it, connect below, and choose the printer from the list. --list will print the same list in the terminal if you'd rather see it there.

2. Point this device at it

The bridge prints its own address when it starts. Use the LAN one if the printer is on a different computer to this browser.

3. Choose the printer

Connect to a bridge above and its printers will appear here.

On windows try the exact printer name from Settings, or a port like COM3. On mac try cups:YourPrinterName or a /dev/cu. device. A network printer is just its address, like 192.168.1.50.

4. Printing

If nothing prints

The site is served over https, and browsers refuse to let an https page talk to a plain http address on another machine. Two ways around it: run the bridge on the same computer as the browser and use http://127.0.0.1:7788, which browsers allow, or open the site over http on the local network at the venue.
